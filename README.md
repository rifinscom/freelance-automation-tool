# Freelance Workflow Automation Tool

A lightweight GUI built with **AutoHotkey v2.0** to optimize repetitive tasks like data entry and clipboard management.

## Features
- **Cut (Ctrl+X)**, **Enter**, and **Paste (Ctrl+V)** buttons in a single floating window.
- **Always-on-top** functionality for seamless multitasking.
- **Zero-Focus-Interruption**: The tool does not take focus away from your active work window.

## Installation
1. Install [AutoHotkey v2.0](https://www.autohotkey.com/).
2. Download the `FreelanceTool.ahk` file from this repository.
3. Double-click the file to run the script.
